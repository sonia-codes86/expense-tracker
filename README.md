# Expense Tracker
A Python program to manage personal expenses.
Data is saved in a JSON file.

## Features
- Add a new expense
- Show all expenses
- Calculate the total amount
- Delete an expense
- Show the most expensive item
- Terminal version and Tkinter  GUI version

## How to run
python expense_manager.py
python expense_tk.py

## Requirements 
Python 3.x (Tkinter is included with Python)
